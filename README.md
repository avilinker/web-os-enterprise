# Web OS - Enterprise Fleet Management Platform

A professional, real-time remote fleet management and virtual session platform built for enterprise environments.

## 🚀 Key Features
- **Role-Based Access Control (RBAC):** Secure separation between Administrator and standard User sessions.
- **Real-Time WebSockets Architecture:** Instant synchronization of states, file edits, and terminal command outputs across clients and admin dashboards using Flask-SocketIO.
- **AWS-Style Console Navigation:** Seamless toggling between global fleet management overviews and dedicated isolated remote PC workspaces.
- **Persistent Memory & State Management:** Live tracking of online/offline node statuses, dynamic server memory storage, and remote terminal execution.

## 🛠️ Tech Stack
- **Backend:** Python, Flask, Flask-SocketIO
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Socket.IO Client
